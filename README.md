Smart Expense Tracker

Smart Expense Tracker is a modern web application built with HTML, CSS, and JavaScript.
It helps you manage personal finances by recording transactions, categorizing expenses, and providing smart insights with filters and summaries.

Features:

Dashboard Summary – View total balance, income, and expenses at a glance.

Add Transactions – Log income or expenses with amount, date, and category.

Smart Filters – Filter transactions by day, week, month, year, or category.

Insights – See top expense category and savings status instantly.

Clear All – Reset all transactions with one click.

Modern UI – Dark theme, responsive layout, and clean design.


Tech Stack:

Frontend: HTML5, CSS3, JavaScript (Vanilla JS)

Design: Responsive grid layout, dark theme

Data Handling: In-memory transaction storage (no backend required)
